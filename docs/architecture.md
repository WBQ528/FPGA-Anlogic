# 系统架构

A板：TF/FAT16读取 → BMP缩放或HXV分块解码 → RGB565 SDRAM帧缓存 → 图层与显示参数处理 → HDMI音视频输出。

视频为HXAV0007格式，每个4×4块包含两个RGB565端点和16个2位索引。FPGA插值恢复调色板，并按索引生成像素。独立PCM音轨采用优先读卡调度与跨时钟域缓冲，实际音频消费进度作为媒体时间依据。

B板：本地TF加载地图与园区图片 → 帧缓存及页面合成 → 地图路线、介绍页、游览清单与二维码 → HDMI输出。B板同时接入串口屏并转发A板媒体控制。

两板使用1000BASE-T全双工链路和自定义有界协议交换控制、媒体时间、状态和字幕字形。视频和图片从各板本地TF读取，不通过以太网传输视频流。

跨时钟域消息、会话与序号、CRC、超时及实际状态回读用于控制一致性。协议受理与画面实际提交是不同阶段，界面以应用状态回读更新。

手机导览为独立静态前端，URL的r参数表示1—4园区编号组成的不重复游览顺序。二维码由FPGA运行时编码，手机网页负责图文展示和清单呈现。地图连线表达顺序，不是道路导航。
