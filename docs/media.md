# 媒体与显示规格

视频内容：1280×720、30fps、2160帧、72秒，HXV（HXAV0007）分块格式。该格式不是MP4/H.264直接解码。

A板HDMI输出画布1280×960，总时序1480×1000，像素时钟约74.166667MHz，刷新率约50.1126Hz；视频位于画布中间720行。视频帧率和HDMI刷新率应分别理解。

讲解音轨NARR.PCM为48kHz、16位、单声道；输出左右声道复制同一轨。MUSIC.HXA提供图片模式配乐。波形来自实际PCM数据。

A板八图尺寸依次为640×480、720×540、960×555，以及五张1280×720。四种图片转场为百叶窗、传送带、随机线条、翻转。支持等比、裁切、拉伸和50%—150%缩放，以及亮度/对比度调节。

B板包含一张地图、十二张园区图片与通用中文字库；实际图片的源尺寸可不同，由FPGA适配至显示区域。B板输出1280×720。四园编号依次为月季、百卉、珍稀、芙蓉；园区顺序与图片编号由运行逻辑管理。

每板8MiB SDRAM使用约7.03125MiB的固定RGB565帧缓存，媒体总数不等于同时驻留帧数。TF卡按需读取；介质吞吐不足时视频调度可跳过迟到帧，不能把文件30fps规格解释为任意卡速下都可满帧播放。
