# 硬件连接与操作

两块HX4S20C分别连接自己的TF卡及HDMI_B显示设备。A端显示设备需支持HDMI音频，或配套适当音频输出设备。两板通过以太网连接，两个SW4均启用网络。

串口屏接B板：115200、8数据位、无校验、1停止位；B RX为D14/J1.1（接屏TX），B TX为G11/J1.2（接屏RX），GND可用J1.12/J1.30。屏幕供电与IO电平按设备手册核对，两板TX不可并接。完整管脚与电气标准以各板pin.adc为准。

## 演示操作

1. 确认A/B固件、TF卡、屏幕工程对应后上电，等待资源加载和网络状态就绪。
2. 在A图片页选择图片、前后切换、自动轮播或暂停；在显示/音画页面设置转场、适配、亮度、对比度、音量等参数。
3. 进入视频页播放完整讲解，或从B园区页面点播对应章节。
4. 在B端浏览四园介绍、地图和三张园区图片；按需要切换跟随/自由浏览。
5. 在游览清单中增删和调整顺序，观察FPGA生成的路线及二维码；使用手机扫码查看随行图文导览。
6. 字幕页可选择预设或用内置拼音输入，最多32字符；图片模式支持A/B自定义字幕同步。视频保留按媒体时间播放的讲解字幕。

实体按键保留本地切图、轮播/暂停及B导览选择等操作；具体仲裁及模式由顶层、media_controls和b_local_controls实现。常规播放不需要电脑端脚本。
