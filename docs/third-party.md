# 第三方组件与素材

本工程使用安路平台提供的PLL、FIFO、SDRAM及HDMI相关IP，其中包含加密Verilog封装。相关文件保留原始标记，适用条件以供应方原有资料为准。

串口屏图标使用IconPark资源。上游项目：https://github.com/bytedance/IconPark 。已有Apache-2.0许可文本保留于`HMI/assets/icons/IconPark_B/LICENSE`，资源按原集合分目录保存。

园区图文、图片、音频、视频及中文字库构成本应用的展示资源。TF目录及校验值见media/files.json，手机导览图文见mobile-guide。它们的公开再分发范围需按各自来源确认，不因收录本工程而自动获得统一开源许可。

当前不为全部代码、加密IP与媒体统一指定开源许可证。后续公开时应按组件分别说明来源、作者和适用许可。
