# 构建与下载

## 开发环境

- Anlogic TD 6.2系列，原工程记录版本为6.2.168116。
- FPGA器件：EG4S20BG256；平台：HX4S20C。
- 串口屏：TJC4827T143_011，480×272；原生HMI编辑器用于打开HMI工程并导出TFT。

## FPGA工程

1. 在TD中打开对应板的`design/td_project/BQ_FPGA_A.al`或`BQ_FPGA_B.al`。
2. 确认器件、顶层、管脚和时序约束。A顶层为`top_tf_hdmi_audio`，B顶层为`top_b`。
3. 使用工程中保存的策略执行综合、布局布线和Bitstream生成。
4. 检查无缺失ROM/IP、无构建错误，核对建立/保持时序后再使用新生成固件。

保留工程现有目录关系；`.vh`、`.mem`、`.ipc`及官方IP封装均为工程输入。编译无需Python脚本或个人环境配置。不要通过放宽时钟/约束获得表面通过结果。

## 已有固件

`firmware/A`与`firmware/B`分别存放配套bit/bin。TD下载时选择对应板的固件。固件校验见根目录SHA256清单。

## 串口屏

使用原生编辑器打开`HMI/project`中的HMI文件。`HMI/src`提供对应事件代码，`HMI/assets`保留当前界面资源；HMI为包含原生控件及资源的完整可编辑工程。已有TFT可用于配套屏幕下载。下载操作及供电遵循设备手册。

## TF卡

从完整RAR获取`media/A.img`和`media/B.img`，分别写入对应板TF卡。写卡前确认目标设备，写入会覆盖所选卡内容；不要混用两板镜像。镜像内容和校验见媒体说明。
